# 🎨 CSS Learning & Projects Hub

Welcome to my **CSS Learning Repository**! This repo contains all my practice files, code snippets, notes, and exercises structured strictly according to the **9 Chapters** of the **CodeWithHarry** CSS course.

---

## 📌 Syllabus & Chapter Breakdown

Below is the chapter-by-chapter roadmap tracking my progress through Harry's course modules:

- [ ] **Chapter 1: Introduction to CSS**
  - Installing VS Code, Live Server & Chrome DevTools setup
  - Ways to add CSS: Inline, Internal & External CSS
  - Basic CSS Selectors: Element, Class (`.`), and ID (`#`)
  - CSS Comments and Syntax

- [ ] **Chapter 2: Colors, Backgrounds & Typography**
  - Text formatting (`font-family`, `font-size`, `font-weight`, `line-height`)
  - Color Systems: Names, `RGB`, `HEX`, and `HSL`
  - Background properties: `background-color`, `background-image`, `background-size`, `background-repeat`
  - Text Alignment and Styling Links

- [ ] **Chapter 3: The CSS Box Model**
  - Understanding Content, Padding, Border, and Margin
  - Border styles, width, and `border-radius`
  - Margin Collapse and Universal Box Sizing (`box-sizing: border-box`)
  - Width, Height, `max-width`, and `min-width`

- [ ] **Chapter 4: Display & Positioning**
  - Display property: `block`, `inline`, `inline-block`, and `none`
  - Float and Clear properties (`clearfix` hack)
  - CSS Position property: `static`, `relative`, `absolute`, `fixed`, and `sticky`
  - Stacking order with `z-index`

- [ ] **Chapter 5: CSS Flexbox**
  - Flex Container vs. Flex Items
  - Main Axis & Cross Axis concepts
  - `flex-direction`, `justify-content`, `align-items`, and `flex-wrap`
  - Item sizing: `flex-grow`, `flex-shrink`, `flex-basis`, and `order`
  - **Mini-Exercise:** Building a responsive navbar with Flexbox

- [ ] **Chapter 6: Responsive Design & Media Queries**
  - Mobile-First vs. Desktop-First design approach
  - Viewport Meta Tag (`meta name="viewport"`)
  - CSS Media Queries (`@media screen and (max-width: ...)`)
  - Fluid Typography & CSS Units (`px`, `%`, `rem`, `em`, `vw`, `vh`)

- [ ] **Chapter 7: Advanced CSS & Pseudo-Selectors**
  - Attribute & Pseudo-Class Selectors (`:nth-child`, `:hover`, `:active`, `:focus`)
  - Pseudo-Elements (`::before` and `::after`)
  - Shadow Effects: `box-shadow` and `text-shadow`
  - Native CSS Custom Properties (CSS Variables)

- [ ] **Chapter 8: CSS Grid & Layouts**
  - Introduction to CSS Grid Architecture
  - `grid-template-columns`, `grid-template-rows`, and `gap`
  - Spanning items with `grid-column` and `grid-row`
  - Dynamic layouts with `fr` unit, `minmax()`, `repeat()`, and `auto-fit` / `auto-fill`
  - `grid-template-areas` for full-page layout design

- [ ] **Chapter 9: Transforms, Transitions, Animations & Final Projects**
  - CSS Transforms (`translate`, `scale`, `rotate`, `skew`)
  - Smooth state changes using CSS `transition`
  - Keyframe Animations (`@keyframes`, `animation-duration`, `animation-iteration-count`)
  - **Capstone Projects:**
    - Project 1: Responsive Navigation Bar
    - Project 2: Interactive Portfolio/Landing Page Layout
    - Project 3: CSS Grid Dashboard
